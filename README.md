# CampusAgenda – TP3 React Native

## Description
CampusAgenda est une application mobile développée avec React Native et TypeScript dans le cadre du TP3 autonome.

L'application permet d'afficher les événements du campus, de consulter les places restantes et de connaître le statut de chaque événement.

## Fonctionnalités
- Affichage de la liste des événements.
- Calcul du nombre de places restantes.
- Détermination du statut : ouvert, presque complet ou complet.
- Affichage des statistiques globales.
- Filtrage des événements : tous les événements ou ateliers disponibles.
- Affichage d'un message lorsqu'aucun événement n'est disponible.

## Technologies utilisées
- React Native
- Expo
- TypeScript

## Installation

```bash
npm install
npx expo start
```

## Objectif pédagogique
Pratiquer les composants React Native, les props, les fonctions JavaScript, les tableaux, `filter()`, `reduce()` et `FlatList`.
